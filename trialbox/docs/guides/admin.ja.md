# TrialBox ガイド：管理者

TrialBox が各画面で表示するヘルプから作成しているため、画面の説明と同じ内容です。研修用に印刷してください。最新版はヘルプから開けます。

## あなたの役割

システムを運用します：アカウント、稼働状況、処理、データソース。承認やマークは行いません。

## TrialBox でできること

リクエストの開始とレジストリの管理; 研究支援部門の年間件数（少数は非表示）; 施設の設定と施設情報; このボックスの REDCap 接続と API キー; リストア後の保留の確認と解除; 処理の開始; EDC 事前入力; 運用：バックアップ、更新、ログ、ネットワーク表; 失敗した本機の夜間処理を同じ入力で再実行; アカウント：パスワード、無効化、再有効化; 患者1名または処理1件のブレイクグラス（60分、レビューあり）; ブレイクグラス許可の閲覧; サポートセッションの開始と終了（すべての患者ページを閉じる、最長2時間）; モデル、ビルド、プロンプトが関わった記録（検索はすべて記録）; データ運用：各ソースの夜間取込（保留された取込の判断はデータスチュワード）

## 使う画面

### ホーム

ホーム：あなたの役割の仕事を、急ぐものから並べています。

### 実施可能性レポート

この病院で各基準を満たす患者数と、月あたりの見込み数です。小さい数は範囲で表示します。

### レポート

担当の試験の確定した実施可能性レポートです。

### 管理

システムの稼働状況、処理（中止・再実行）、データソースです。赤い表示からここへ来ます。対処は運用手順書にあります。

### ユーザー

このボックスのアカウントです。追加、パスワードの再設定、担当試験の変更、停止ができます。患者を見るアカウントは、もう一人が確認してから開設されます。

### アカウントの申請

別の担当者による確認を待つアカウントの変更です。一件ずつ確認または却下します。自分の申請は確認できません。

### 緊急アクセス

一人の患者の記録への緊急アクセスです。開かれた許可、その理由、それぞれに必要な事後確認を表示します。

### データ運用

病院の夜間データです。読み込まれた夜と保留された夜、チェックが指摘した表、保留された夜への判断を表示します。

### 実行履歴

実行した、または実行中のすべての処理を新しい順に表示します。

### アカウント

あなたのアカウント：担当の試験、言語、パスワード。

### 受け取った通知

TrialBox から送られた通知を新しい順に表示します。

### 通知の設定

TrialBox からのメールの時刻と言語を設定します。

### 依頼を始める

処理を開始します。このページのボタンを押すまで何も実行しません。

### プロトコルを送る

基準を貼り付けるかアップロードすると、実施可能性レポートを作成します。

### コマンド欄

コマンド欄が理解した内容、または理解できなかったときの入力例です。

### 施設の設定

施設の準備：3つの質問、まだやること、確認するリスト。

### TrialBox に質問

TrialBox に質問：次にやること、患者がリストにいる理由をリンク付きで答えます。

## 試せるコマンド

各画面上部のコマンド欄に入力します。STUDY はあなたの試験のコードに置き換えてください。

- `処理`
- `データソース`
- `システム状態`
- `ユーザー`

## 困ったときは

施設の TrialBox 管理者に相談してください。連絡先は各画面のヘルプにあります。
