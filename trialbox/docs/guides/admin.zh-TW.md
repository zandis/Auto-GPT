# TrialBox 使用手冊（管理者）

本手冊由 TrialBox 在各畫面顯示的說明產生，內容與畫面一致。請列印作為訓練教材；最新版可從說明頁開啟。

## 您的職責

您維持系統運作：帳號、狀態、作業與資料來源。您不核准也不標記。

## TrialBox 讓您能做的事

發起請求與維護登錄; 研究辦公室的年度件數（小數字隱藏）; 院所的設定與院所資訊; 本機的 REDCap 連線與 API 金鑰; 還原後的暫停：檢視與解除; 啟動作業; EDC 預填; 維運：備份、更新、日誌、網路表; 以相同輸入重新執行本機失敗的夜間作業; 帳號：密碼、停用、重新啟用; 一位病人或一個作業的緊急存取（60 分鐘，會審查）; 閱讀緊急存取授權; 資料作業：各來源的夜間匯入（保留的匯入由資料管理員決定）

## 您使用的畫面

### 首頁

您的首頁：依您的角色列出作業，最急的在前。

### 本週病人

可能符合條件的病人及其下次門診。開啟病人可看到原因，並標記「邀請」「需要更多資訊」或「暫不邀請」。

### 可行性報告

本院符合各項條件的病人數，以及每月預估人數。低於小格限制的數字以範圍顯示。

### 報告

您負責試驗的定稿可行性報告。

### 系統管理

系統狀態、作業（可取消與重試）與資料來源。紅色狀態會連到此處，處理方式見作業手冊。

### 執行紀錄

系統執行過或執行中的所有作業，最新的在前。

### 您的帳號

您的帳號：負責的試驗、語言與密碼。

### 收到的通知

TrialBox 寄給您的通知，最新的在前。

### 通知設定

設定 TrialBox 寄信給您的時間與語言。

### 登錄庫

候選登錄：研究團隊對每位代號病人的進度。

### 開始一項請求

啟動作業。按下本頁按鈕之前不會執行任何動作。

### 送出試驗計畫書

貼上或上傳條件，產生可行性報告。

### 指令欄

指令欄理解的內容，或無法理解時的範例。

### 院所設定

院所準備：三個問題、還要做的事，以及需要確認的清單。

### 詢問 TrialBox

詢問 TrialBox：回答下一步該做什麼、病人為什麼在名單上，並附上連結。

## 可以試試的指令

在任一畫面上方的指令欄輸入；STUDY 代表您的試驗代碼。

- `作業`
- `資料來源`
- `系統狀態`
- `使用者`

## 需要協助時

請洽本院的 TrialBox 管理者；各畫面的說明頁有聯絡方式。
