# TrialBox 使用手冊：管理者

本手冊由 TrialBox 在各畫面顯示的說明產生，內容與畫面一致。請列印作為訓練教材；最新版可從說明頁開啟。

若要將主控台安裝為應用程式，請在 Windows 的 Edge 選擇「安裝」，在 macOS 的 Safari 選擇「加入 Dock」，或在 iOS 的 Safari 選擇「分享」→「加入主畫面」。在 Android 上，請從瀏覽器選單選擇「安裝」或「加到主畫面」。裝置必須信任醫院資訊部門提供的憑證授權單位（CA）。若使用 FSLogix 虛擬桌面，請在瀏覽器中開啟主控台。

## 您的職責

您維持系統運作：帳號、狀態、作業與資料來源。您不核准也不標記。

## TrialBox 讓您能做的事

發起請求與維護登錄; 研究辦公室的年度件數（小數字隱藏）; 院所的設定與院所資訊; 本機的 REDCap 連線與 API 金鑰; 還原後的暫停：檢視與解除; 啟動作業; EDC 預填; 維運：備份、更新、日誌、網路表; 以相同輸入重新執行本機失敗的夜間作業; 帳號：密碼、停用、重新啟用; 一位病人或一個作業的緊急存取（60 分鐘，會審查）; 閱讀緊急存取授權; 開始或結束支援作業時段（關閉所有病人頁面，最長 2 小時）; 模型、建置或提示詞涉及的紀錄（每次查詢皆記錄）; 資料作業：各來源的夜間匯入（保留的匯入由資料管理員決定）

## 您使用的畫面

### 首頁

您的首頁：依您的角色列出作業，最急的在前。

### 可行性報告

本院符合各項條件的病人數，以及每月預估人數。低於小格限制的數字以範圍顯示。

### 報告

您負責試驗的定稿可行性報告。

### 系統管理

系統狀態、作業（可取消與重試）與資料來源。紅色狀態會連到此處，處理方式見作業手冊。

### 使用者

本裝置上的帳號：新增、重設密碼、變更負責的試驗或停用。能看到病人的帳號須由另一人確認後才會開通。

### 帳號申請

等待另一人確認的帳號變更：逐筆確認或拒絕。任何人都不能確認自己的申請。

### 緊急存取

對單一病人紀錄的緊急存取：已開啟的授權、其原因，以及每筆需要的事後審查。

### 資料作業

醫院的夜間資料：每一晚已載入或被暫停的資料、檢查指出的資料表，以及您對被暫停那晚的決定。

### 執行紀錄

系統執行過或執行中的所有作業，最新的在前。

### 您的帳號

您的帳號：負責的試驗、語言與密碼。

### 收到的通知

TrialBox 寄給您的通知，最新的在前。

### 通知設定

設定 TrialBox 寄信給您的時間與語言。

### 開始一項請求

啟動作業。按下本頁按鈕之前不會執行任何動作。

### 送出試驗計畫書

貼上或上傳條件，產生可行性報告。

### 指令欄

指令欄理解的內容，或無法理解時的範例。

### 院所設定

院所準備：三個問題、還要做的事，以及需要確認的清單。

### 詢問 TrialBox

詢問 TrialBox：回答下一步該做什麼、病人為什麼在名單上，並附上連結。

## 可以試試的指令

在任一畫面上方的指令欄輸入；STUDY 代表您的試驗代碼。

- `作業`
- `資料來源`
- `系統狀態`
- `使用者`

## 需要協助時

請洽本院的 TrialBox 管理者；各畫面的說明頁有聯絡方式。
