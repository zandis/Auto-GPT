# TrialBox 使用手冊：資料管理員

本手冊由 TrialBox 在各畫面顯示的說明產生，內容與畫面一致。請列印作為訓練教材；最新版可從說明頁開啟。

若要將主控台安裝為應用程式，請在 Windows 的 Edge 選擇「安裝」，在 macOS 的 Safari 選擇「加入 Dock」，或在 iOS 的 Safari 選擇「分享」→「加入主畫面」。在 Android 上，請從瀏覽器選單選擇「安裝」或「加到主畫面」。裝置必須信任醫院資訊部門提供的憑證授權單位（CA）。若使用 FSLogix 虛擬桌面，請在瀏覽器中開啟主控台。

## 您的職責

您負責病人資料：事後審查緊急存取、處理資料來源間的不一致、決定被暫停的夜間資料、維護人員名冊與拒絕研究使用登記，並為各試驗指定主持人。

## TrialBox 讓您能做的事

還原後的暫停：檢視與解除; 帳號：密碼、停用、重新啟用; 審查每一次緊急存取; 閱讀緊急存取授權; 維護退出登記; 維護人員名錄; 依簽署的紀錄寫入試驗主持人; 給 CRO 帳號依訪視的監測授權; 稽核軌跡中的假名代碼; 院內稽核軌跡：篩選、單一病人報告、驗證雜湊鏈（每次閱讀皆記錄）; 模型、建置或提示詞涉及的紀錄（每次查詢皆記錄）; 臨床項目目錄; 臨床資料矛盾（檢視與解決）; 資料作業：各來源的夜間匯入（保留的匯入由資料管理員決定）; 記錄未符合條件的院方確認

## 您使用的畫面

### 首頁

您的首頁：依您的角色列出作業，最急的在前。

### 可行性報告

本院符合各項條件的病人數，以及每月預估人數。低於小格限制的數字以範圍顯示。

### 報告

您負責試驗的定稿可行性報告。

### 帳號申請

等待另一人確認的帳號變更：逐筆確認或拒絕。任何人都不能確認自己的申請。

### 緊急存取

對單一病人紀錄的緊急存取：已開啟的授權、其原因，以及每筆需要的事後審查。

### 稽核軌跡

誰在何時做了什麼：每次登入、每次檢視病人與每次修改，可依人員、試驗或病人查詢。

### 臨床資料不一致

兩個資料來源不一致的數值，例如兩個出生日期。附上原因保留其一；紀錄會保留兩者。

### 資料作業

醫院的夜間資料：每一晚已載入或被暫停的資料、檢查指出的資料表，以及您對被暫停那晚的決定。

### 拒絕研究使用登記

拒絕研究使用的病人。以病歷號登錄紙本或電話的拒絕，該病人會立即從所有清單中移除。

### 人員名冊

可列入試驗授權紀錄表的醫院人員，及其科別與聯絡方式。

### 執行紀錄

系統執行過或執行中的所有作業，最新的在前。

### 您的帳號

您的帳號：負責的試驗、語言與密碼。

### 收到的通知

TrialBox 寄給您的通知，最新的在前。

### 通知設定

設定 TrialBox 寄信給您的時間與語言。

### 登錄庫

候選登錄：研究團隊對每位代號病人的進度。

### 指令欄

指令欄理解的內容，或無法理解時的範例。

### 詢問 TrialBox

詢問 TrialBox：回答下一步該做什麼、病人為什麼在名單上，並附上連結。

## 需要協助時

請洽本院的 TrialBox 管理者；各畫面的說明頁有聯絡方式。
