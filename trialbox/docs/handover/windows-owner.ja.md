# TrialBox ワークステーション: 責任者のためのページ

ボックスの責任者（病院の IT 部門ではなく、研究の責任者）のためのページです。3 つの部分があります: 設置する日、
ふだんの日、何かおかしいときにすること（NEW-WIN-9、D-611）。この PC は Windows で動き、TrialBox はその中で
動いて、誰もいない夜間に処理を行います。

実際の Windows PC での最初のリハーサルより前に書かれています。このページと PC が違うときは PC が正しく、
その違いを私たちに知らせてください。

## 設置する日

1. ボックスの所有者となる Windows 管理者アカウントでサインインします。以後、TrialBox にはこのアカウントを使います。
2. PC に NVIDIA ドライバーがまだない場合は、USB ディスク上のもの（`windows\nvidia`）をインストールします。
3. USB ディスクの `Install-TrialBox.cmd` をダブルクリックし、実行を許可します。Windows の再起動が必要なときは、
   同じアカウントでもう一度サインインしてください。インストーラーは自動で続きを行います。
4. ドライブごとに、48 桁の BitLocker 回復キーが表示されます。書き留めるか印刷し、保管する人（病院の IT 部門。
   封をした封筒で）に渡してから、末尾の 6 桁を入力します。インストーラーは控えを残しません。このキーがないと、
   PC のセキュリティチップが故障したときにドライブの内容が失われます。
5. 次に、コードとアドレスが表示されます。この PC のブラウザーでアドレスを開き、コードを入力して、設定ページに
   答えます。ウィンドウに「TrialBox is ready」と出たら完了です。
6. この PC をデスクトップとして使う人それぞれに通常の（標準）Windows アカウントを作り、
   「TrialBox ワークステーションをデスクトップとして使うとき」のページを渡します。

## ふだんの日

- PC の電源は入れたままにします。サインアウトするか画面をロックし、シャットダウンはしないでください。TrialBox は夜間にカルテを読みます。
- 停電や再起動のあと、TrialBox は誰かがサインインする前に自動で起動します。
- Windows は夕方に更新をインストールし、19:00 から 01:00 の間に自動で PC を再起動することがあります。夜間処理をこの時間帯に入れないでください。
- 1 日に 1 回、コンソールのヘルス表示を見てください。緑なら何もする必要はありません。
- バックアップは病院の共有フォルダーか外付け USB ディスクに保存します。この PC だけに置くことはしません。

## 何かおかしいとき

| 見えているもの | すること |
| --- | --- |
| コンソールが開かない | PC の電源は入っていますか。再起動のあとは 5 分待ちます。次に、この PC 自身で開いてみます（`https://localhost/`）。ここでは開くのにほかのコンピューターから開かない場合は、病院の IT 部門に伝えてください。ネットワークが変わっています |
| ヘルス表示が赤で、グラフィックスカードについて書かれている | デスクトップのプログラムがカードを使っています。そのプログラムを閉じてください（デスクトップ利用のページに一覧があります）。このために PC を再起動しないでください |
| ヘルス表示が赤で、バックアップについて書かれている | 外付けディスクは接続されていますか。共有フォルダーに届きますか。そのうえで次の夜を待ちます |
| 起動時に Windows が BitLocker 回復キーを求める | 設置の日に受け取ったキーを入力します。もう一度起きたら私たちに知らせてください |
| メモリー、ディスク、グラフィックスカードを交換した | `Install-TrialBox.cmd` をもう一度ダブルクリックします。正しい設定は何も変わりません |
| そのほか | 再インストールはしないでください。ファイル `C:\ProgramData\TrialBox\box-install\box-install.log` と、ヘルス表示の内容を私たちに送ってください |

誰に勧められても、次のことは決してしないでください: WSL という Windows の機能や、その中の `TrialBox` という
システムを削除または「リセット」すること。Docker Desktop をインストールすること。Linux 用の NVIDIA ドライバーを
インストールすること。ボックスのディスクファイルを「バックアップとして」どこかにコピーすること。どれも、データを
失うか、ボックスを止めます。
