# TrialBox：給醫院資訊室的一頁說明（由資訊室安裝的主機）

**Reader:** hospital IT（醫院資訊室）。由資訊室安裝主機（RUNBOOK §1：加密磁碟上的作業系統、Docker、顯示卡驅動程式）；之後主機需要資訊室協助的是以下 9 件事。完整的連接埠表在[網路說明表](network-sheet.zh-TW.md)。

由主機自己的檢查清單（`libs/tb_common/preflight.py`）經 `tools/it_one_page.py` 產生（10K-18, D-1378）；請勿手動編輯。主機會自行檢查每一項（`doctor --preflight`，RUNBOOK §1），未完成前以紅色或黃色顯示，並附上下列說明。

## 需要資訊室協助的事項

### 網路

- **主機名稱與憑證**：請醫院資訊人員把主機名稱加入院內 DNS（指向主機的位址）；若使用醫院憑證，請簽發含此名稱的憑證。
- **時鐘與校時伺服器**：請醫院資訊人員讓主機連得到院內校時伺服器（NTP），並把位址告訴主機供應商；等時鐘同步。
- **郵件轉送伺服器**：請向醫院資訊人員確認郵件轉送伺服器的名稱與連接埠，並請其接受來自主機的郵件。

### 儲存

- **備份共用資料夾**：請選擇主機以外的備份位置（第二顆磁碟或醫院的共用資料夾），並請醫院資訊人員給主機寫入權限。
- **稽核紀錄共用資料夾**：請醫院資訊人員準備主機以外的一次寫入（WORM）共用資料夾：主機可以新增檔案，但檔案寫入後，包括主機管理者（root）在內，任何人都不能修改或刪除。

### 醫院資料

- **醫院資料來源**：請醫院資訊人員把匯出資料放到主機讀取的資料夾，並讓主機可以讀取；這一行會顯示找到的檔案數。

### 硬體

- **磁碟剩餘空間**：請清出主機磁碟空間，或聯絡主機供應商更換更大的磁碟。
- **金鑰保護（TPM；磁碟解鎖另需 Tang）**：請在主機的韌體設定中啟用 TPM 2.0：主機把金鑰封存在 TPM。若磁碟解鎖使用 Tang，除了 TPM 還需要醫院的任一台 Tang 伺服器回應：請醫院資訊人員讓主機連得到。沒有 TPM 時請聯絡主機供應商。
- **顯示卡與等級紀錄**：顯示卡或記憶體與這台主機的等級紀錄不符：請先聯絡主機供應商再繼續。

## 位址與防火牆設定

- 主機的一個固定位址（以 DHCP 保留即可），以及院內 DNS 的一個名稱：擁有者將它填入 `TB_TLS_HOSTNAME`，同仁以瀏覽器開啟 `https://<該名稱>`。
- **進：** 從診間電腦所在網路到主機的 TCP 443。主機上沒有其他可連入的服務。
- **出：** 不需要網際網路：更新以簽章媒體送達，試驗清單也隨每次更新提供。只有在安裝時醫院選擇即時使用 ClinicalTrials.gov 的情況下：到 `clinicaltrials.gov` 的 TCP 443。
- **院內：** 到時間伺服器的 UDP 123；到備份與稽核紀錄共用資料夾的 NFS 2049 或 SMB 445；若指定郵件轉送伺服器，則為其連接埠。

關於主機的問題請先洽擁有者；由擁有者聯絡主機供應商（RUNBOOK §7）。
