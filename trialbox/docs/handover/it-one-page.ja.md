# TrialBox: 病院情報システム部門向けの1ページ

**Reader:** hospital IT（病院情報システム部門）。機器の設定と運用は機器の管理者（オーナー）が行います。情報システム部門に
お願いするのは、以下の3点だけです（T-735, D-729）。ポートの一覧は[ネットワークシート](network-sheet.ja.md)にあります。

## 1. アドレス

- 院内ネットワーク上の固定アドレスを1つ（DHCPの予約で構いません）。
- そのアドレスに対する院内DNSの名前を1つ。オーナーはこれを `TB_TLS_HOSTNAME` に書きます。職員はブラウザで
  `https://<その名前>` を開きます。
- 証明書：機器がその名前で自分で作成するか、情報システム部門が病院のCAから発行します（RUNBOOK §12）。

## 2. データの接続

- 機器が毎晩読む出力データの、読み取り専用フォルダまたは共有（病院のデータ出力、またはEDCの出力）。機器が
  そこへ書き込むことはありません。
- 機器外へのバックアップ：機器が書き込める共有（NFS 2049 または SMB 445）、またはオーナーが接続する外付け
  ディスク。どちらか一方で、オーナーが選びます。
- 任意：朝の通知のための病院のメールリレー（SMTP）、病院アカウントでのサインインのためのドメインコントローラー
  （LDAPS 636）。どちらも無くても機器は動きます。

## 3. ファイアウォールの設定

- **受信：** 診察室のPCのネットワークから機器への TCP 443。それ以外に機器へ届くものはありません。
- **送信：** ありません。機器はインターネットを必要としません。更新は署名付きの媒体で届き、試験の一覧も更新に
  含まれます。インストール時に病院が ClinicalTrials.gov のオンライン利用を選んだ場合のみ：`clinicaltrials.gov`
  への TCP 443。
- 機器の時計：病院の時刻サーバーへの UDP 123。

機器についての質問は、まずオーナーへ。オーナーが Aimedics に連絡します（RUNBOOK §7）。
