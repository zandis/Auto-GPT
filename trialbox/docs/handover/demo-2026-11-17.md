# The TrialBox demo of Tuesday 2026-11-17: the script of clicks

**Reader:** the box owner, and whoever presents the demo with him.

For the presenter, who may never have used TrialBox. About 15 minutes. One study (GZQO, a synthetic gout trial), one
hospital of synthetic patients, two people: the owner (an investigator) and the guest (a study coordinator).

Every step below was clicked in a real browser on the frozen demo image on 2026-11-16 (lane G; local rehearsal of the
same image, the same boot script, the same Caddy), built from master `9e6d04cb` (train 45, image sha256
`268b9069…73bd`), as the investigator and as the guest: 34 of 34 checks passed. The times are what each click took
there, plus time to talk. The figures to say aloud are the frozen image's, each marked with that commit.

**Why the figures moved since Monday's image (master `2d354036`, train 37):** train 42 (`25658c7c`) made "a missing
record never excludes", so patients with no record for a criterion now go to review instead of "not matched".

## Before you start

| What | How |
| --- | --- |
| Your link | The lead sends each person one private line: a one-time link (it holds the address, the user name and a one-time code), with the user name and the code also written out. Nobody else needs it. Do not paste it into a shared chat. |
| The certificate warning | The browser warns once, because the demo uses its own certificate. Choose "Advanced", then "Proceed" (Chrome) or "Accept the risk" (Firefox). It does not come back on that device. |
| Enrol with your link | Open your link, best in a private window. The page fills your user name and code by itself, and removes the code from the address bar. Choose a password. If the two fields stay empty, type the user name and the code from your line. |
| The password | At least 12 characters. You choose it; nobody else knows it. The link works once and is then dead. An unused link expires after 24 hours. |
| The 12-hour stop | The demo machine switches itself off 12 hours after it starts. If it was started early in the morning, it is off by evening. The lead can start it again; that makes new accounts and new links. |
| The language | The demo is seeded in Chinese (Taiwan): the coordinator's tasks, the seeded note and the signature text are in Traditional Chinese. The pages open in your browser's language: Japanese or Chinese (Taiwan) if the browser is set so, otherwise English. To switch: at the top right, choose the language in the box next to your name, then click "Change". The script below names the English labels. |
| The banner | A dark band at the top says "Demonstration with synthetic data only". It is on every page, on purpose. |

### What the guest cannot see

As a coordinator the guest cannot open the site's whole audit trail, the settings or the accounts: these pages answer
"This page needs another role". The whole audit trail is for the privacy office and the data steward only. Neither demo
person has that role, on purpose; steps 13 and 14 show the trail of one participant instead.

## If something goes wrong

| What happens | What to do |
| --- | --- |
| The page does not open | Check the address (https, no www). If it still fails, the machine may be off (12 hours after its start) or still starting (about 10 minutes after the lead starts it). Ask the lead. |
| The certificate warning | Expected once per device. Accept it (see "Before you start"). |
| "The user name or the enrolment code is not right" | The link was used already, expired (24 hours), or the code was mistyped. A new link needs a new start of the machine: ask the lead. |
| Locked out after five wrong passwords | Wait 15 minutes. The lock is for that user from that address only; the other person is not affected. |
| "Not accepted in the demonstration" | By design. The demo refuses every upload and every pasted chart text, so no real record can enter it. Say so and go back. |
| "This page needs another role" | By design: that role may not open that page. Click "My home page". |
| "Data as of ...: more than two days old" | Not expected on Tuesday: the seed plays the last working day before the day the machine starts, so on Tuesday the data is as of Monday. The rehearsal ran on a Monday and showed Friday's date with this line. If it shows, say once that the synthetic hospital is loaded at the machine's start. |
| A Japanese or Chinese phrase on an English page | Some synthetic notes and tasks are written in Japanese or Chinese, as a hospital's would be. |

Avoid this, which works but distracts: "Single case" under "More" (it needs a chart upload, which the demo refuses;
step 7b shows the seeded one instead). On the frozen image the SAE register no longer shows the investigator the
set-up warnings of each study's SAE rule set (the coordinator still sees them), and the last criterion's English label
reads in full, "Any other drug trial within 30 days."

## What is real and what is not

- **The patients are synthetic.** No real patient is in the demo. Names, numbers, notes and dates are made up.
- **The model on the demo image is a stub.** The criteria read from the notes are marked "test model": a fixed test
  stand-in gives those answers, not the real language model. The counts of the feasibility report use no model at all.
- **The real pair's figures come from the evidence page**, not from this demo: see the closing section.
- **The software is a pre-release proof of concept**, not validated and not a medical device. A person decides on every
  output.
