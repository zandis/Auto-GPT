# Windows が BitLocker 回復キーを求めたとき

**Reader:** the box owner, and the person who keeps the recovery keys.

Windows が起動する前に、「BitLocker 回復」という青い画面が「このドライブの回復キー」を求めることがあります。この
ページはそのときにすることを説明します（NEW-WIN-14、D-617）。Linux 版の「ロックされたボックス」のページに代わる
ものです。所有者向けのほかのページ: `windows-owner.ja.md`。

実際の Windows PC での最初のリハーサルの前に書かれています。このページと画面が違うときは画面が正しいので、
私たちに知らせてください。

## 表示されるもの

- Windows のサインインの前に、「BitLocker 回復」という題と、48 桁を入力する欄。この画面は常にシステムドライブ
  C: のためのものです。
- キー ID（key ID）: 画面が求めているキーを示す 8 文字の英数字。
- 画面が待っている間に失われるものはありません。必要なだけこの画面のままで構いません。

## すること

1. 同じキー ID のキーを探します。設置の日に、インストーラーは各ドライブのキーをキー ID とともに表示し、印刷した
   ページにもキー ID が載っています。ここではドライブ C: のキーです。
2. 48 桁を入力します。ハイフンは自動で入ります。数字キーが効かないときは、画面の説明どおり、ファンクションキー
   F1 から F10 で 1 から 9 と 0 を入力できます。
3. Windows が起動し、TrialBox は自動で起動します。5 分待ってから、コンソールのヘルス表示を確認します。
4. 起きた日と、その直前に起きたこと（ファームウェアや BIOS の更新、部品の交換、PC の移動）を知らせてください。
   キーそのものは、どんな連絡にも書かないでください。

## データドライブがロックされたとき

- データドライブは、Windows が起動すると自動で開きます。開かないときは青い画面は出ず、サインイン後に
  エクスプローラーでドライブに鍵のマークが付き、TrialBox は起動しません。
- ドライブをダブルクリックし、回復キーの入力を選びます。そのドライブの回復キーならどれでも開けます。ウィンドウ
  に表示されたキー ID のキー、一致するものがなければ、設置の日にデータドライブ用に受け取ったキーです。
- 持っているどのキーでも開かないときは、ほかのことをする前に私たちに連絡してください。別の方法で開ける
  ことがあります。

## 起きる理由

- ファームウェアや BIOS の更新、ブートマネージャーやセキュリティチップの更新、またはセキュリティ設定（セキュア
  ブート、起動順序）の変更。
- PC の起動時に USB メモリ、ドッキングステーション、ほかのディスクがつながっていたとき。
- マザーボードの交換、セキュリティチップの消去、またはドライブを別の PC に移したとき。
- 起動時に PIN を使う設定（`tpm_pin`）で、PIN を何度も間違えたとき。
- 起動のたびにこの画面が出るときは、まず USB メモリとディスクをすべて外し、ドッキングステーションから外して
  再起動します。それでも出るときは、セキュリティチップがドライブを開けなくなっています。何よりも先に知らせて
  ください。

## どのキーでも開かないとき

1. 直前に変えたことがあれば元に戻し（セキュアブートの設定、起動順序、つないだディスク）、再起動します。多くの
   場合、セキュリティチップがまた自分でドライブを開きます。
2. 病院の IT 部門にキー ID を調べてもらいます。病院のドメインや Microsoft Entra に参加している PC、Microsoft
   アカウントでサインインしている PC は、そこにキーの写しを持っていることがよくあります（Active Directory、
   Entra、Microsoft アカウント）。
3. 私たちに連絡してください。

3 つとも見つからなかったときに初めて、キーは失われたことになります。そのときは誰もドライブを開けず、私たちにも
開けられず、中身は失われます。残るのは病院の共有フォルダーか外付けディスクのバックアップで、作り直したボックス
への戻し方は `WINDOWS-BACKUP-RESTORE.md` にあります。画面を通り抜けるために BitLocker をオフにしようとしたり、
ツールでドライブを「修復」しようとしたりしないでください。データが確実に失われます。
