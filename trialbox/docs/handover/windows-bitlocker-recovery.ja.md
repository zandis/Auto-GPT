# Windows が BitLocker 回復キーを求めたとき

**Reader:** the box owner, and the person who keeps the recovery keys.

Windows が起動する前に、「BitLocker 回復」という青い画面が「このドライブの回復キー」を求めることがあります。この
ページはそのときにすることを説明します（NEW-WIN-14、D-617）。Linux 版の「ロックされたボックス」のページに代わる
ものです。所有者向けのほかのページ: `windows-owner.ja.md`。

実際の Windows PC での最初のリハーサルの前に書かれています。このページと画面が違うときは画面が正しいので、
私たちに知らせてください。

## 表示されるもの

- Windows のサインインの前に、「BitLocker 回復」という題と、48 桁を入力する欄。
- キー ID（key ID）: 画面が求めているキーを示す 8 文字の英数字。
- 画面が待っている間に失われるものはありません。必要なだけこの画面のままで構いません。

## すること

1. 同じキー ID のキーを探します。設置の日に、インストーラーは各ドライブのキーをキー ID とともに表示し、印刷した
   ページにもキー ID が載っています。
2. 48 桁を入力します。ハイフンは自動で入ります。数字キーが効かないときは、画面の説明どおり、ファンクションキー
   F1 から F10 で 1 から 9 と 0 を入力できます。
3. Windows が起動し、TrialBox は自動で起動します。5 分待ってから、コンソールの状態表示を確認します。
4. 起きた日と、その直前に起きたこと（ファームウェアや BIOS の更新、部品の交換、PC の移動）を知らせてください。
   キーそのものは、どんな連絡にも書かないでください。

## 起きる理由

- ファームウェアや BIOS の更新、またはそのセキュリティ設定（セキュアブート）の変更。
- マザーボードの交換、またはセキュリティチップの消去。
- ドライブを別の PC に移したとき。
- 起動のたびにこの画面が出るときは、セキュリティチップがドライブを開けなくなっています。何よりも先に知らせて
  ください。

## キーをなくしたとき

キーがなければ、誰もドライブを開けません。私たちにも開けられず、中身は失われます。残るのは病院の共有フォルダーか
外付けディスクのバックアップで、作り直したボックスへの戻し方は `WINDOWS-BACKUP-RESTORE.md` にあります。この画面を
通り抜けるために BitLocker をオフにしようとしたり、ツールでドライブを「修復」しようとしたりしないでください。
データが確実に失われます。
