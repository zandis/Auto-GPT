# Windows 要求 BitLocker 修復金鑰時

**Reader:** the box owner, and the person who keeps the recovery keys.

在 Windows 啟動之前，一個標題為「BitLocker 修復」的藍色畫面可能會要求「此磁碟機的修復金鑰」。本頁說明此時該
怎麼做（NEW-WIN-14，D-617）。它取代 Linux 版的「鎖定的 box」頁面。給擁有者的其他頁面：`windows-owner.zh-TW.md`。

本頁寫於第一次在真正的 Windows 電腦上演練之前：本頁與畫面不同時，以畫面為準，並請告訴我們。

## 您會看到

- 在 Windows 登入之前，標題「BitLocker 修復」和一個輸入 48 位數的欄位。這個畫面一定是為系統磁碟機 C: 而出現。
- 金鑰 ID（key ID）：八個英數字元，指出畫面要的是哪一組金鑰。
- 畫面等待時不會遺失任何東西。電腦可以停在這個畫面，需要多久都可以。

## 該做的事

1. 找出金鑰 ID 相同的那組金鑰。安裝那天，安裝程式顯示每個磁碟機的金鑰時都附上了金鑰 ID，列印的頁面上也有：
   這裡是磁碟機 C: 的那一組。
2. 輸入 48 位數。連字號會自動加上。如果數字鍵沒有反應，可依畫面說明用功能鍵 F1 到 F10 輸入 1 到 9 和 0。
3. Windows 啟動後，TrialBox 會自行啟動。等五分鐘，再看主控台的健康狀態列。
4. 告訴我們發生的日期，以及發生前剛做過什麼（韌體或 BIOS 更新、更換零件、移動電腦）。任何訊息中都不要寫金鑰
   本身。

## 資料磁碟機被鎖住時

- Windows 啟動後，資料磁碟機會自行開啟。若沒有開啟，不會出現藍色畫面：登入後，檔案總管中的磁碟機會顯示鎖頭
  圖示，TrialBox 也不會啟動。
- 按兩下該磁碟機，選擇輸入修復金鑰。該磁碟機的任何一組修復金鑰都能開啟它：視窗所顯示金鑰 ID 的那組；若都不
  相符，就用安裝那天為資料磁碟機拿到的那組。
- 如果您手上沒有任何一組能開啟它，請先聯絡我們，再做其他任何事：磁碟機可能還有其他方法能開啟。

## 為什麼會發生

- 韌體或 BIOS 更新、開機管理員或安全晶片更新，或安全設定（安全開機、開機順序）有變更。
- 電腦啟動時接著 USB 隨身碟、擴充座或其他磁碟。
- 更換主機板、安全晶片被清除，或磁碟機被拿到另一台電腦。
- 使用開機 PIN 的設定（`tpm_pin`）時，PIN 輸錯太多次。
- 如果每次開機都出現這個畫面：先拔下所有 USB 隨身碟和磁碟、取下擴充座，再重新啟動。若仍然出現，表示安全晶片
  已無法開啟磁碟機：請先告訴我們，再做其他任何事。

## 如果沒有任何金鑰能開啟磁碟機

1. 如果剛做過變更（安全開機設定、開機順序、接上的磁碟），先改回原狀再重新啟動：安全晶片常常就會再自行開啟
   磁碟機。
2. 請醫院資訊部門查詢這個金鑰 ID：加入醫院網域或 Microsoft Entra 的電腦，或以 Microsoft 帳戶登入的電腦，常常
   在那裡留有金鑰的副本（Active Directory、Entra、Microsoft 帳戶）。
3. 聯絡我們。

三項都找不到時，金鑰才算遺失。那時任何人都打不開磁碟機，我們也不行，上面的內容就沒了；剩下的是醫院共用資料夾
或外接磁碟上的備份：`WINDOWS-BACKUP-RESTORE.md` 說明如何放回重建的 box。不要為了通過這個畫面而嘗試關閉
BitLocker，或用工具「修復」磁碟機：那一定會遺失資料。
