# 您的 TrialBox 工作站：負責人專頁

**Reader:** the box owner（主機負責人）。

寫給主機的負責人（研究負責人，不是醫院資訊部門）。分成三個部分：安裝的那一天、平常的一天、出現問題時
該做什麼（NEW-WIN-9、D-611）。這台電腦執行 Windows；TrialBox 在其中執行，並在夜間無人時工作。

本頁寫於第一次在實際 Windows 電腦上演練之前：若本頁與電腦不同，以電腦為準，也請告訴我們。

## 安裝的那一天

1. 以將擁有這台主機的 Windows 系統管理員帳戶登入。之後 TrialBox 都使用這個帳戶。
2. 如果電腦還沒有 NVIDIA 驅動程式，請安裝 USB 磁碟上的版本（`windows\nvidia`）。
3. 在 USB 磁碟上按兩下 `Install-TrialBox.cmd` 並允許執行。如果 Windows 需要重新啟動，請用同一個帳戶再次登入：
   安裝程式會自行繼續。
4. 每個磁碟機都會顯示一組 48 位數的 BitLocker 修復金鑰。請抄下或列印，交給保管人（醫院資訊部門，放入密封
   信封），然後輸入最後六位數。安裝程式不會留存副本。沒有這組金鑰，電腦的安全晶片故障時，磁碟機的內容就會
   遺失。
5. 接著視窗會顯示一組代碼和一個網址。在這台電腦的瀏覽器開啟該網址，輸入代碼，並回答設定頁面。視窗顯示
   「TrialBox is ready」時即完成。
6. 為每位把這台電腦當作桌上型電腦使用的人建立一般（標準）Windows 帳戶，並把
   「把 TrialBox 工作站當作桌上型電腦使用」那一頁交給他們。

## 平常的一天

- 讓電腦保持開機。請登出或鎖定螢幕；不要關機。TrialBox 在夜間讀取病歷。
- 停電或重新啟動之後，TrialBox 會在任何人登入之前自行啟動。
- Windows 在傍晚安裝更新，並可能在 19:00 到 01:00 之間自動重新啟動電腦。請不要把夜間作業排在這段時間。
- 每天看一次主控台的健康狀態列。綠色就不需要做任何事。
- 備份存放在醫院的共用資料夾或外接 USB 磁碟，絕不只放在這台電腦上。

## 出現問題時

| 您看到的情況 | 該做什麼 |
| --- | --- |
| 主控台打不開 | 電腦有開機嗎？重新啟動後請等五分鐘。然後在這台電腦上開啟（`https://localhost/`）。如果這裡打得開、其他電腦打不開，請告訴醫院資訊部門：網路有變動 |
| 健康狀態列變紅並提到顯示卡 | 桌面上有程式正在使用顯示卡。請關閉它（桌面使用那一頁列出了是哪些）。不要為此重新啟動電腦 |
| 健康狀態列變紅並提到備份 | 外接磁碟接上了嗎？共用資料夾連得到嗎？然後等下一個夜間 |
| 開機時 Windows 要求 BitLocker 修復金鑰 | 輸入安裝那天拿到的金鑰。如果再次發生，請告訴我們 |
| 更換了記憶體、磁碟或顯示卡 | 再按兩下 `Install-TrialBox.cmd` 一次。正確的設定不會被更動 |
| 其他情況 | 請不要重新安裝。把檔案 `C:\ProgramData\TrialBox\box-install\box-install.log` 和健康狀態列的內容寄給我們 |

不論誰建議，都絕對不要做以下的事：移除或「重設」名為 WSL 的 Windows 功能，或其中名為 `TrialBox` 的系統；
安裝 Docker Desktop；安裝 Linux 用的 NVIDIA 驅動程式；把主機的磁碟檔複製到別處「當作備份」。每一項都會
遺失資料或讓主機停止運作。
