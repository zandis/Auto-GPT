# TrialBox：給醫院資訊室的一頁說明

**Reader:** hospital IT（醫院資訊室）。主機由主機負責人（擁有者）設定與管理；需要資訊室協助的只有以下三件事
（T-735, D-729）。完整的連接埠表在[網路說明表](network-sheet.zh-TW.md)。

## 1. 位址

- 主機在院內網路上的一個固定位址（以 DHCP 保留即可）。
- 該位址在院內 DNS 的一個名稱。擁有者將它填入 `TB_TLS_HOSTNAME`；同仁以瀏覽器開啟 `https://<該名稱>`。
- 憑證：由主機以該名稱自行產生，或由資訊室從醫院的 CA 簽發（RUNBOOK §12）。

## 2. 資料連線

- 主機每晚讀取的匯出資料所在的唯讀資料夾或共用（醫院的資料匯出，或 EDC 的匯出）。主機不會寫入該處。
- 主機外的備份：主機可寫入的共用（NFS 2049 或 SMB 445），或由擁有者接上的外接硬碟。兩者擇一，由擁有者決定。
- 選用：早晨通知所用的醫院郵件轉送（SMTP），以及以醫院帳號登入所用的網域控制站（LDAPS 636）。兩者都沒有，主機
  也能運作。

## 3. 防火牆設定

- **進：** 從診間電腦所在網路到主機的 TCP 443。主機上沒有其他可連入的服務。
- **出：** 無。主機不需要網際網路：更新以簽章媒體送達，試驗清單也隨每次更新提供。只有在安裝時醫院選擇即時使用
  ClinicalTrials.gov 的情況下：到 `clinicaltrials.gov` 的 TCP 443。
- 主機的時鐘：到醫院時間伺服器的 UDP 123。

關於主機的問題請先洽擁有者；由擁有者聯絡 Aimedics（RUNBOOK §7）。
