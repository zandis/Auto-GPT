# D-732 The handover pages name their reader too

- **Task:** T-735b, the second documents part of T-735 (after T-735a, D-729)
- **PR:** this branch (`agent/T-735b-the-handover-pages-name-their-reader`), stacked on T-735a
- **Date:** 2026-11-14
- **Status:** accepted
- **Builds on:** D-729 (every RUNBOOK page names its reader), D-138 (the generated network sheet), D-611

## Context

D-729 made every RUNBOOK page name its reader and left the handover pages unchecked: the pages that leave with the
box (the owner's pages, the install checklist, the offline media, the desktop rules, the network sheet). Some said
"For the box owner" in their own words, the desktop-use and network-sheet pages said nothing, and the network sheet
is generated, so a line written into it by hand would be overwritten.

## Decision

1. Every Markdown page of `docs/handover/` has a `**Reader:**` line under its title, as the RUNBOOK's pages do
   (`tools.doclint.handover_problems`, part of `make doclint`).
2. `tools/network_sheet.py` writes the sheet's reader line (hospital IT, handed over with IT's one page) in the three
   languages, in the Markdown and the HTML sheet; the committed sheets are regenerated by the tool, not edited.
3. The readers: the owner's pages and the backup page the box owner; the install checklist the box owner or
   Aimedics; the offline media Aimedics and the owner; the P-0 pages the owner (and the builders for the result);
   the desktop rules the trial team; the network sheet and IT's one page hospital IT.

## Not covered

- The HTML sheets are not linted (they are printed); they carry the same line.
