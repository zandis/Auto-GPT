- **Decision:** new `tb_common.audit_text`: `mask_free_text` masks as the reveal note always has (D-272's `mask_ids`, the note masker with the site's chart-number pattern, any run of six or more digits; `reveal.clean_note` now calls it), and `mask_free_text_in` does so under every `note`, `reason`, `why` and `comment` key of a detail, at any depth. Ids, pseudonyms and states are never touched.
