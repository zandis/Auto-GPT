# D-1158 A note, a reason or a comment a person types is masked before it reaches the audit chain

- **Task:** the register's open Highs for the console, card AUDIT-TEXT (posted on #639): V3-14 (the break-glass opening note), V8-03 (the data-ops decision's reason, page and /api/v1) and V8-07's typed reason (the IRB record), sent by the integrator on 2026-11-19. · **Date:** 2026-11-19
- **Decision:** new `tb_common.audit_text`: `mask_free_text` masks as the reveal note always has (D-272's `mask_ids`, the note masker with the site's chart-number pattern, any run of six or more digits; `reveal.clean_note` now calls it), and `mask_free_text_in` does so under every `note`, `reason`, `why` and `comment` key of a detail, at any depth. Whitespace is folded first, so a label and its value on two lines are one span. The console's audit writer is wrapped (`FreeTextMasked`) as soon as it is opened, so every console event (sign-in's too) is masked whatever page writes it, free text nested in any argument included; the not-matched check's `record` is masked where it is written; `datacore.dataops` masks the reason in every decision event (the accept's started and ended too), and the orchestrator's `life.step` masks a step's and an undo's reason, in the chain only (the batch's step row and the subject's step row keep what was typed; they are not the chain). The adversarial review's two HIGHs (the accept path, the unfolded label) and its MED (the undo note) are fixed here. Ids, pseudonyms and states are never touched.
- **Left:** V8-07's order (the IRB record stored before its event) is card AUDIT-ORDER's, so its row stays open; a name typed with no label is outside the masker's scope (V5-13).
- **Held by:** the pinned tests, moved: their strict xfails on V3-14 (`test_asvs_evidence.py`), V8-03 and V8-07's text (`test_audit_trail_routes.py`) are removed and they pass; `test_no_driven_route_writes_typed_text_in_clear` (every route the audit walk drives) `tests/unit/test_typed_text_is_masked_before_the_chain.py` and `tests/console/test_an_undo_note_is_masked_in_the_chain.py`, synthetic data only (failing output kept: `audtext-base-fail.txt`, `audtext-review-fail.txt`).
