# TrialBox 概念実証（PoC）：データの取り扱い

PoC data-handling statement v1, 2026-11-10（データ取扱説明 第1版）。1ページの説明で、初回サインインの前に各テスター
にお渡しします（[英語版](data-handling.en.md)、[繁體中文版](data-handling.zh-TW.md)）。末尾の確認事項は初回
サインイン時にコンソールに表示されるものと同じで（D-328）、アカウント、日時、この版とともに記録されます。
ほかに署名するものはありません（D-332）。

訳語について：ネイティブの読み手による署名は不要になりました（D-311 B12）。文言の誤りは PoC の指摘事項として
お知らせください。

## 説明

1. **これは何か。** 研究の支援ツール TrialBox のデモ版です。診療記録を試験の適格基準と照合します。病院の外、台湾
   にあるホスティングサーバー（Google Cloud、リージョン `asia-east1`）で動いています。開発中のソフトウェアで、
   バリデーション未了であり、**医療機器ではありません**。
2. **中のデータは実在しません。** デモ内の患者、カルテ、氏名、番号、日付はすべて合成データ（生成プログラムで作成）
   または公開研究データです。病院のデータは含まれていません。実在の人物に似ていても偶然です。
3. **患者さんの情報を入力しないでください。** 実在の患者さんの記録から、入力・貼り付け・アップロード・撮影を一切
   しないでください。どの欄、ファイル、コメント、フィードバックでも同じです。氏名、カルテ番号、生年月日、記載文、
   画像、個人を特定しうる珍しい情報も含みます。デモはカルテの貼り付けとアップロードを拒否しますが、この決まりは
   自由記述欄とフィードバックにも当てはまります。
4. **診療にも治験の実施にも使いません。** 出力を患者さんの診療、適格性、声かけ、同意の判断に使わないでください。
   ここにあるものは治験記録、スクリーニングログ、原資料、GCP の必須文書のいずれでもありません。結果は誤っている
   ことがあります。デモはテスト用モデルを使っています。
5. **あなた自身のデータ。** 氏名、役割、所属、メールアドレス、アカウント名、サインインと操作のログ（時刻、ページ、
   操作）、いただいたフィードバック（書面、通話での発言、そのつど同意いただいた場合のみ画面録画）を保持します。
   目的：試用の運営、サービスの安全確保、製品の改善。管理者：Aimedics（正式名称と所在地はアカウントとともに
   お知らせします）。連絡先：プロジェクトオーナー。販売や共有はしません。フィードバックは氏名ではなく記号で整理し、
   氏名付きの引用はご本人の同意がある場合だけです。詳細は「テスター自身のデータについてのお知らせ」
   （[testers-data.md](testers-data.md)）にあります。
6. **保存場所と期間。** データは台湾の Google Cloud に保存されます。日本のテスターにとっては日本国外への移転です。
   移転先の国は台湾で、同国の個人情報保護の法律は「個人資料保護法」です。アカウントとログは試用終了の 90 日後に
   削除し、フィードバックは氏名を除いて保持します。
7. **あなたの権利。** いつでも、理由を言わずに、データの開示・訂正・削除を求めること、参加をやめることができます。
8. **問題が起きたとき。** 誤って患者さんの情報が入力された場合は、当日中にプロジェクトオーナーにお知らせください。
   当方で削除し、それを含むスナップショットとログを消去し、内容を含めずに事象を記録し、何をしたかをお伝えします。
   ご自身の病院の報告ルールにも従ってください。
9. **フィードバックの位置づけ。** 製品設計への意見です。適格性確認（クオリフィケーション）の証拠でも、あなたを
   対象とする研究でもありません（D-332）。試用の結果を公表したい場合は、事前にあなたにお尋ねします。
10. **秘密保持。** ソフトウェアとその画面は公開まで秘密情報です。

これは計画の作成者による草案であり、法的助言ではありません。

>
> - [ ] 本デモ環境の患者データはすべて合成データまたは公開データであることを理解しています。
> - [ ] 実在の患者さんの情報は、入力・貼り付け・アップロード・記述のいずれも行いません。

>   理解しています。

>   します。

> - [ ] （任意）フィードバックを氏名付きで引用することに同意します。

必須は 5 項目、任意の 2 項目は空欄でもかまいません。同意するとアカウントごとに一度だけ監査イベント `demo.ack` が
記録されます。
