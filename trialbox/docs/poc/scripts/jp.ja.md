# PoC 試用スクリプト：日本サイト（日本語）

| 項目 | 内容 |
| --- | --- |
| サイト | `jp`：日本のもの忘れ外来のデモサイト（合成データ、Asia/Tokyo） |
| 試験 | AD-MAB（早期アルツハイマー病、抗アミロイド抗体、第3相企業治験、シナリオ J1）、NEUR-COH（MCI・認知症レジストリ、シナリオ J2） |
| アカウント | 責任医師（PI）用、分担医師用、CRC 用の各1つ（共有しないこと） |
| 版 | 1.0、2026-11-10、カード T-508 |
| 英語版 | [jp.en.md](jp.en.md)。タスク番号は両方のファイルで同じです。 |
| 確認方法 | `tests/integration/test_poc_scripts.py` が英語版の全タスクを現在の master で実行して確認します |

使い方。タスクは順番に行ってください。セッション A は PI のパートと分担医師のパート、セッション B は CRC
のパートのあと、アンケートと振り返りです（[../forms.md](../forms.md)）。各タスクの後に、やりやすさを 1〜7
でセッション記録に付けてください。「期待される結果」は画面に出るべき内容で、それ以外はすべて指摘事項です。
「既知の不足」は、まだ画面に出ない結果です。どの程度困るかを教えてください。「時間」は初めて使う人の目安で、
目標ではありません。

画面上の患者、氏名、医師、番号はすべて合成データです。実在の患者さんの情報は一切入力しないでください。

訳語について：画面の文言は現在のコンソールの日本語表示に合わせています。ネイティブの読み手による署名は不要に
なりました（D-311 B12）。文言の誤りは PoC の指摘事項として記録してください。

その後ファシリテーターとの振り返り。

このスクリプトにないもの（テスターにも伝えます）：全ページ下部の「この画面へのご意見」（カード
T-510。問題の種類、評価、コメント。セッション記録と併せていつでもお使いください）、スマートフォン表示（ご自分のスマートフォンで試して教えてくだ
さい）、朝の通知、EDC 事前入力（台湾サイトのみ）、実モデルによる記録の読み取り（PoC のステップ 2）。
