# PoC 試用腳本：台灣站點（繁體中文）

| 項目 | 內容 |
| --- | --- |
| 站點 | `tw`：台灣風濕免疫科的展示站點（合成資料，Asia/Taipei） |
| 試驗 | RA-JAK（類風濕性關節炎，JAK 抑制劑，第三期廠商試驗，情境 T2）、GZQO（痛風第三期廠商試驗，含一次計畫書修正，情境 T1）、GOUT-COH（研究者自行發起的痛風登錄研究，含 REDCap 預填，情境 T3） |
| 帳號 | 主持人（PI）、協同主持人、研究護理師（CRC）帳號各一個（不可共用） |
| 版本 | 1.0，2026-11-10，卡片 T-508 |
| 英文版 | [tw.en.md](tw.en.md)。兩個檔案的任務編號相同。 |
| 檢查方式 | `tests/integration/test_poc_scripts.py` 在目前的 master 上逐一執行英文版的每項任務 |

使用方式。請依序進行：A 場次是主持人部分，接著是協同主持人部分；B 場次是研究護理師部分，之後填寫問卷並與
引導者回顧（[../forms.md](../forms.md)）。每項任務後，在場次紀錄上為難易度打分（1 到 7）。「預期結果」是畫面
應該出現的內容，其他任何情況都是發現事項。「已知缺口」是主控台目前還做不到的結果，請告訴我們它有多重要。
「時間」是第一次使用者的參考，不是目標。

站點上的病人、姓名、醫師與號碼全部是合成資料。請勿輸入任何真實病人的資訊。

用語說明：畫面文字依照目前主控台的繁體中文顯示。母語讀者簽署已取消（D-311 B12），用語錯誤請記為 PoC 發現事項。

| TW-PI-09 | 回到 RA-JAK，開啟「未符合條件之病人」。選一位病人閱讀原因，寫下看起來錯誤之處，按「這是錯的，送回審閱」。 | 每列顯示條件、答案的來源與證據。送出後：「已送回審閱，並連同您的姓名記錄」。 | 6 分鐘 |
| TW-PI-10 | 在已邀請的病人（TW-PI-07）的「病歷號」選擇需要的原因，按「顯示病歷號」。 | 合成的病歷號只顯示一次；重新開啟頁面後就不見了。檢視會連同您的帳號與原因記錄。 | 2 分鐘 |
