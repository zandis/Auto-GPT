# TrialBox 概念驗證（PoC）：資料如何處理

PoC data-handling statement v1, 2026-11-10（資料處理說明第 1 版）。一頁說明，於第一次登入前交給每位測試者
（[英文版](data-handling.en.md)、[日本語版](data-handling.ja.md)）。文末的確認聲明與主控台第一次登入時顯示的
內容相同（D-328），會連同帳號、時間與本版本一起記錄。除此之外不需簽署任何文件（D-332）。

用語說明：母語讀者簽署已取消（D-311 B12）。用語錯誤請當作 PoC 發現事項告訴我們。

## 說明

1. **這是什麼。** 研究輔助工具 TrialBox 的展示版本，用來將病歷與試驗收案條件比對。它在醫院之外、位於台灣的託管
   伺服器上運作（Google Cloud，區域 `asia-east1`）。這是開發中的軟體，尚未完成確效，**不是醫療器材**。
2. **其中的資料不是真的。** 展示環境中的每位病人、病歷、姓名、號碼與日期都是合成資料（由產生程式製作）或來自公開
   研究資料集。不含任何醫院的資料。若與真實人物相似，純屬巧合。
3. **請勿輸入病人資訊。** 請勿在任何欄位、檔案、留言或回饋表單中，輸入、貼上、上傳或拍攝任何真實病人病歷的內容，
   包括姓名、病歷號、出生日期、病歷文字、影像，以及可辨識個人的罕見細節。展示環境會拒絕貼上病歷與上傳檔案；此規則
   也適用於自由填寫欄位與您的回饋。
4. **不可用於臨床，也不可用於試驗執行。** 請勿以任何輸出決定病人的照護、資格、邀請或同意。這裡的任何內容都不是
   試驗紀錄、篩選紀錄、原始文件或 GCP 必要文件。結果可能有誤；展示環境使用的是測試用模型。
5. **您自己的資料。** 我們保存您的姓名、角色、所屬機構、電子郵件、帳號名稱、登入與操作紀錄（時間、頁面、動作），
   以及您提供的回饋（書面、通話中的發言，以及僅在您每次同意時的螢幕錄影）。目的：執行本次試用、維護服務安全、
   改善產品。管理者：Aimedics（正式名稱與地址隨帳號一併提供）。聯絡人：專案負責人。我們不會出售或分享這些資料。
   回饋以代號而非姓名歸檔；只有在您同意時才會具名引用。細節請見「測試者個人資料告知」（[testers-data.md](testers-data.md)）。
6. **存放地點與期間。** 資料存放在台灣的 Google Cloud（對日本的測試者而言，這是移轉至日本境外，適用台灣的
   《個人資料保護法》）。帳號與紀錄於試用結束後 90 天刪除；回饋去除姓名後保留。
7. **您的權利。** 您可以隨時、無須說明理由，要求查閱、更正或刪除您的資料，或停止參與。
8. **發生問題時。** 若不慎輸入了病人資訊，請於當天告知專案負責人。我們會刪除該資訊，清除含有它的快照與紀錄，
   在不記錄內容的情況下記錄此事件，並告訴您處理結果。您也須遵守自己醫院的通報規定。
9. **您的回饋是什麼。** 產品的設計意見。不是確效證據，也不是以您為對象的研究（D-332）。若日後希望發表試用結果，
   會先徵詢您的同意。
10. **保密。** 軟體及其畫面在正式發布前均屬機密。

本文為計畫撰寫者的草稿，並非法律意見。

>
> - [ ] 本人了解本展示環境之病人資料皆為合成資料或公開資料。
> - [ ] 本人不輸入、貼上、上傳或描述任何真實病人之資訊。
> - [ ] 本人不將任何輸出用於病人照護、資格判定、同意取得或試驗紀錄。
> - [ ] 本人了解本軟體為開發中版本，尚未完成確效，非醫療器材，其輸出可能有誤。
> - [ ] 本人同意帳號資料、操作紀錄與回饋意見依說明用於本次試用之執行與產品改善。
> - [ ] （選填）本人同意回饋會議中錄製螢幕。
> - [ ] （選填）本人同意回饋意見得具名引用。
>
> **我接受。** 以（帳號）（角色）身分接受。時間與說明版本隨帳號記錄。

五項為必選，兩個選填項目可不勾選。接受後，每個帳號只記錄一次稽核事件 `demo.ack`。
