Is TrialBox ready to sell to a hospital?

Not yet. TrialBox is a working proof of concept that has only ever run in the cloud on public and synthetic data. It is close to being offered as a paid, scoped pilot at one hospital, but five things outside the code have to happen first: a run on the DGX Spark, a run on real hospital records, a legal basis and IRB route, a pilot contract, and confirmed model licences.

Works today (cloud, synthetic data)

  • One-command Docker POC with admin console and e-mail in/out
  • FEAS, SCREEN, protocol questions, consent explainer (EN/JA/zh-TW)
  • 920+ unit tests, browser and mail end-to-end tests
  • Model pair gpt-oss-120b + Gemma 4: 8 of 79 eligible pairs lost (same as TrialGPT's GPT-4), 0.9% wrong blocks, about US$0.04 per 1,000 checks

Has never happened

  • A run on the DGX Spark (GB10) with the real models
  • A run on a real hospital's records or Chinese/Japanese clinical notes
  • Hermes with a real model proposing a run (fixed in code today, rerun pending)
  • A hospital IT security review, IRB submission or signed contract

Blocks a first paid pilot

Ranked by how much each one stops a hospital from signing. Items 1 to 5 need you or the pilot site; items 6 to 8 were code and are fixed on the draft PR.

1

No real hospital data yet

BlockerOwner: pilot site + Changfu

Recall is measured only on the English TrialGPT benchmark and the MIMIC demo. The Taiwan mapping (tw_core) has never seen a real HIS export, and zh-TW notes have never been judged. A hospital will ask "how many of our eligible patients does it miss?" and we cannot answer yet. Needed: a de-identified extract under an IRB-approved protocol, or an on-site run, plus a recall check on 50 to 100 known screened patients.

2

Never run on the DGX Spark

BlockerOwner: Changfu (hardware access)

make spark-e2e passed 12/12 only with a placeholder model in the cloud. Whether gpt-oss-120b and Gemma 4 fit together in the GB10's 128 GB, and how fast a SCREEN runs there, is unknown. This is the product's whole on-premise promise. Needed: one run on the Spark, or the GCP stand-in if you provide credentials.

3

Legal basis, IRB route and hospital security review

BlockerOwner: Changfu + site; we can draft the documents

Screening records for recruitment is secondary use under Taiwan's PDPA and the Human Subjects Research Act. The pilot needs the hospital's legal basis and IRB position, a data protection impact assessment, and the hospital's information-security questionnaire. None of these documents exist yet, though the architecture (on-premise, no patient data leaves the box, audit chain, human confirms every candidate) answers most questions.

4

No contract, data processing terms or price

BlockerOwner: Changfu

There is no pilot agreement, data processing agreement, support terms or price. A pilot can be a short fixed-fee agreement with success criteria (for example, recall on a known cohort and hours saved per screen), but it has to exist before a hospital procurement office will move.

5

Model and dataset licences unconfirmed

BlockerOwner: Changfu / counsel

Every open model in models/registry.yaml is marked verified: false (Gemma terms, NVIDIA open model licence versions). The Chia corpus licence is still open. Commercial use needs each one confirmed and recorded.

6

Hermes with a real model never proposed a run

Fixed in code, rerun neededStress test #26

gpt-oss-120b answered "no record of study GZQO" 7 times out of 7. Now: a front-desk instruction file per Hermes profile, refusals that name the wrong field with an example, tolerant look-back and study parsing, and the exact line to confirm is always added to the reply. Needs one real-model run. The native engine (19/20 correct) is the fallback.

7

One bad criterion failed the whole protocol

FixedStress test #24

A model-made criterion that cannot be compiled now goes to human review with a compile_error flag; the rest of the protocol compiles.

8

Hospital TLS inspection broke outbound calls

FixedStress test #21

Set TB_EXTRA_CA to the hospital CA file; the services that call out trust it alongside the public CAs.

For a repeatable product, later

Second site and remote fleet updates, ISO 27001 or SOC 2 path, support hours and an SLA, a second Spark per site for capacity, and the Phase C/D modules that the business case gates on measured recall. Lind Asia (with PREMIA) is localising EHR-embedded screening for Taiwan and Japan, so the first reference site matters more than breadth.
