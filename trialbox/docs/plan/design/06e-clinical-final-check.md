## Annex: method

- Every file in the "reviewed in full" row was read at its exact path on the project mount; the large files were read by the sections named and searched with grep for every D-finding's keywords (shadow, BD-07, RELEASE, re-authentication, EDC-lite / EDCL, 100 h / 78 h, 620 h / 630 h / 895 h / 921 h / 116 h, 01-11 / 01-12 / 01-22 / 01-23, 02-08 / 02-22 / 03-15 / 03-29, week 7 / weeks 1–3, screening number, treating physician / introduce rule / 主治医の了承, resolves identities / opt-out registry, on duty, clinic_days, Not eligible / 対象外 / 不符合, every BD-15..BD-20 citation, every "TB-xx vN.n" citation). Every control-table version was compared with TB-DS-00R v0.6 and every change-history tail was read. Nothing in any other design file was changed. The repository was not re-read; built-state claims are taken from the documents' own `a1e55fa` statements.
- A D-finding is marked Closed only when the fix appears in the document the finding named *and* no other document in the set (nor the same document elsewhere) contradicts it; any contradiction makes it Partly and produces an E-finding, whatever its severity. This is why four editorial residues count as Partly.
- Scores are per criterion against what a site would do with the document as written; the overall score is the unweighted mean, as in TB-REV-006, 006b, 006c and 006d. Where a finding rests on practice (how CRCs, PIs and committees work in Japanese and Taiwanese hospitals), it is stated as practice to be confirmed in R-02 / R-07, not as regulation; regulatory points cite the same sources the set uses (ICH E6(R3), J-GCP, 生命・医学系指針, HSRA, PDPA) and are not legal advice.
