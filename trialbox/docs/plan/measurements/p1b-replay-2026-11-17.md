## What was not replayed

- **Model verdicts.** Every note verdict is as stored, and so is every `ir_extract`, `concept_map` and `judge` reply.
  On sigir, 8 concept maps the run made had no stored reply. The re-run answered them "no choice", so those criteria
  go to a person.
- **The box's own engines.** The CQL translator, the FHIR server and the box's lake were not run. The equivalence,
  approve and FHIR steps are checked by the cause the P1b review named, not end to end. "Met, cause-level" in
  target 3 means exactly that.
- **Other coded lines.** Only lines whose whole logic is age and sex were decided again. Other coded lines are as
  stored.
- **jmed's birth dates and key v2.** jmed's birth dates are not in the stored run. Each jmed patient's age is placed
  by what their stored coded age verdicts allow, which is key v1's. JMED-DM's age line, now compiled, excludes 34
  patients that JMED-HT's stored verdicts place under 20. No gold row judges those exclusions. Key v2 covers the
  jmed rows whose note the run's judge read in full (319 of 594).
- **tcga.** It cannot be replayed from P1b, which did not run it.
