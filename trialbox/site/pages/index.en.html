On-prem · e-mail and web driven · open source

Find the patients a trial needs, without the data leaving the hospital.

TrialBox is an eligibility compiler and patient-finding appliance that runs inside the hospital. It turns protocols, Taiwan NHI reimbursement rules and cohort definitions into auditable patient screens over the hospital's own records, and answers feasibility questions by e-mail or from an admin console.

Three rules

Data never leaves the hospital

The box runs on a DGX Spark or any Docker host inside the network. Models are served on the box; outbound traffic is blocked by default. Only aggregate, small-cell-suppressed reports go to sponsors.

Agents draft, engines decide

Language models only extract criteria from documents and read free-text notes for what structured data cannot answer. Every count comes from deterministic SQL generated from a reviewed rule set, checked against CQL.

Humans approve

A coordinator approves each compiled rule set in a review workbook, and the investigator decides eligibility. Every request, model call and output file is hashed into an append-only audit trail.

How it works

{{pipeline_en}}

The cascade runs cheap, exact steps first: SQL (S0–S1) removes most patients at no model cost; the lexicon and semantic screens (S2, S2b) decide which notes a model must read; only that residue goes to the note judge (S3) and an overnight second opinion (S4). A person makes the final call (S5). The recall certificate bounds how many eligible patients the exclusions could have missed.

How you use it

By e-mail

Send a one-line command to the box; results come back to your mailbox.

To: trialbox@your-hospital
Subject: FEAS GZQO

Also SCREEN, NAV (NHI navigation), COHORT, and replies with a filled review.xlsx to approve.

From the admin console

The same commands as buttons: new request, protocol upload and review, cascade runs, the e-mail thread and the audit trail of every job. Type a question in Chinese, Japanese or English and the console proposes the exact command; nothing runs until you confirm.
