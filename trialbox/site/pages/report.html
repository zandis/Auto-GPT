Which model should judge the notes?記録の判定にどのモデルを使うか

Candidate open-weights models for the box, run through the TrialBox gateway on the public TrialGPT criterion annotations: 1,015 patient–criterion pairs labelled by physicians, with the notes also rendered in Traditional Chinese, Japanese and mixed text. Hosted endpoints were used for the test; on the box the chosen model runs locally.ボックス搭載候補のオープンウェイトモデルを、TrialBox ゲートウェイ経由で公開データ TrialGPT 基準アノテーション （医師がラベル付けした患者×基準ペア 1,015 件、記録を繁体字中国語・日本語・混在テキストにも変換）で評価しました。テストにはホスティング版を使い、本番では選んだモデルをボックス上で動かします。

TrialGPT (NCBI) matches patients to trials with GPT-4 and its own prompt. The "recorded GPT-4" bars above are the labels stored in the dataset from that run, made with TrialGPT's own prompt in the study that collected the physician labels, so read them as a reference point rather than a like-for-like run.
